# 课务台

当前版本：v2.9.0

HanaAgent 全屏插件，用一个入口查看并操作老苏的排课、事务、提醒和飞书日历看板。显示名为「课务台」，内部插件 ID 保持不变。

## 当前能力

- 全自动：飞书日历差异自愈（检测到差异 10 分钟内自动同步，去重防循环，无需点击）；数据文件变化即时感知（fs.watch）
- 定时事务缺结束时间自动检测成卡，一键按默认时长补齐
- 一条命令发版：npm run release（校验/打包/双槽/自动 commit/重启/确认加载）
- 冲突建议只报真实撞车：缺结束时间等警告类信息不再伪装成冲突卡
- 建议处理「点了就办」：过期课已上/没上、日历同步、批量转复核全部一键执行（后台预演+提交+回读），成功即收起并回扫数据
- 时间冲突进建议处理：事务与课程/事务撞车自动成卡，点开当天看全貌再决策
- 事务页改版：待处理/已安排/已完成·已取消三个状态按键，另配列表/日历双视图——本月事务按状态着色铺进月历（与总览同款），点开任何一天看当天安排与详细交互
- 交互铁律落地：决策类动作全部一键化（本次不上、完成、没约上、取消预留、过期课已上/没上），预演+提交+回读在后台完成；两步以上的事交给 AI
- 过期课建议逐节成卡：看到即决策（老苏即人工），不再转人工复核；超 4 节才提供批量转复核兜底
- 新增快速路由：/api/courses/overdue-complete（转复核+确认完成合并执行）、/api/affairs/complete、/api/reservations/cancel-quick
- 按钮彻底无线化：全站按钮去边框去系统外观，建议卡按钮补齐底色层级
- 事务页固定本月视图（含已完成/已取消留痕），与总览时间范围解耦——这个月做了什么一眼可见
- 按钮彻底无线化：全站按钮去边框、去系统外观，统一纯底色/文字层级
- 总览布局：功能双块（待处理/建议处理）纵向置顶，下接下一节课、收课、指标与课表主体

- 按钮体系统一：同字重同圆角档，主要/次要/危险角色色全走色板；健康点、事务图标、日历对账等残留杂色归入色板
- 驾驶舱并入筹备页「试排」分区，主导航收敛为总览/筹备/事务三页
- 总览新增「建议处理」卡：过期课、到期预约、限期事务、日历差异、明日课表自动成卡，一键预演或推进（场景提炼自真实聊天记录）
- 外部改动自动感知：每 45 秒探测课表/事务库文件变化，变化即静默全量刷新（其他 AI 会话的修改自动带回）
- 事务库每周维护挂入 Hana 定时（周日 23:40 agent prune）
- AI 交互升级：追问带可点选项（点一下继续，不用打字）；一句话出多步批量方案，整批预演、逐条提交、首败即停
- 操作注册表（lib/operations.js）：AI 提示词、路由白名单、Agent 工具枚举同源，新增能力只需加一条定义
- 交互简化第一轮：打开页面秒开（上次数据即显＋后台全量重扫本地课表与事务系统，外部 AI 改动自动带回）；刷新一键扫总览/筹备/驾驶舱/AI 上下文；卡片 hover 只留高频一键（本次不上、完成、没约上），调整时间与取消统一走详情；筹备 5 分区收敛为 3 分区
- 全站无线框化：卡框与按钮去线（输入框保留），以底色和阴影分层；元信息类小字统一加粗，对齐总览参照系
- 全站排版统一：展示层（页标题、指标数字、时刻、阶段数字）全部转无衬线并收进全局字阶，清除残留宋体衬线
- 驾驶舱排版并入全局设计语言：卡色、字号、圆角、today 强调色、每列最小宽度与周视图对齐，不再是突兀的第二套 UI
- 交互语法统一第二轮：总览与筹备共用同一导航组件（workbench-nav），四页统一 PageTitle 标题区，对象级反馈统一为 inline-result 小字
- 留痕规则修正：画布只保留上过课（已完成·石板色）；已取消/已调课不再回到画布；过期未标记课程以琥珀“过期”提示，不再显示为绿色待上课
- 交互语法统一第一轮：轻点即详情、单日聚焦、列数随窗口自适应
- 结束的课程和事务不再从视图消失：周/月/时间轴带留痕展示，已完成用独立石板色，已取消用灰色降低色度
- 对接 schedule events --include-finished 与 timeline --include-finished；冲突检查、简报等链路保持默认过滤
- 新增「修改事务」：改时间、标题、优先级、备注，走 dry-run 预演，带版本与冲突校验，不再需要取消重建
- 「没约上」推进后可在原地一键「撤销推进」（retry-prev，恢复上一候选日），带版本并发保护
- 新建/修改事务支持「办成前每日跟进」（follow_up=daily）：按每日窗口提醒，约上或完成后自动静默
- 对接事务系统 schema 5：follow_up 字段、scan follow_ups 与 agent prune 保留期清理
- 页面启动失败提示使用 textContent 写入，错误消息不再拼接 HTML，消除注入点
- 快照缓存带请求序号门：并发下先发出、后完成的旧读取不会回写新缓存
- 预演提交只要主写入落库就立即失效数据缓存；导出失败时页面同样回读真实状态
- “今日课程已上完”提交前复核当日待上课程快照，预演后课表变化会被拦截并要求重新预演
- 复核处理不再触发重复工作簿导出（底层 review 写入已自动导出）
- 批量调课计划中途失败会写入孤儿计划审计（plan_orphaned），便于定期清理
- 操作文本不允许以“-”开头，避免被底层命令行误认为选项参数
- 事务截止日过期显示“已过 N 天”，不再出现负数天数
- 「课务台」全屏页面，三项主导航保持居中
- AI 操作使用右侧抽屉，保留原页面上下文；系统状态保留为二级入口
- 统一工作台视觉语言：采用无边线模块，以底色、留白和轻阴影区分层级
- 放大顶部三项主导航，强化主要切换入口
- 重新平衡主内容宽度、左右栏比例、卡片高度和模块间距
- 移除顶部重复品牌展示，保留导航与功能入口
- 顶栏左侧留空，主导航保持居中
- 总览、筹备、事务和详情共用同一套无边线颜色语法：绿色表示已确认/已完成，琥珀色表示待确认/待处理，红色表示错误/硬阻塞；临时身份以蓝色小圆点叠加，不覆盖状态色
- 筹备页使用结构化排课数据，按“周视图→资料准备→模板体检→课程预留→正式落课”形成闭环；周视图分临时预留与正式固定两层，窄窗口自动切换为每页三天并提供视图翻页按钮

## 安全契约

- 不直接读取或写入 SQLite
- 排课只调用 `schedule.py agent`
- 事务只调用 `affairs.py agent`
- 调课只使用 `move`，不使用 `cancel + add`
- 所有真实写入必须先 dry-run
- 对接 schedule schema >= 7（contract v2）：课程来源、周期范围、预留关联与单次 availability 覆盖均为结构化字段
- 新建/调课只有在具体单次时间已明确时才传 `--override-availability`，不会修改长期候选时间
- 预演令牌 15 分钟有效、一次性使用
- 正式写入后执行回读；日历同步固定使用 `--prune`
- 事务写入附带 `--request-id` 幂等标识
- 写入前校验排课/事务契约版本和事务 writer 锁
- 预演与提交记录到插件私有审计日志
